# Kurs MPG1: Notation, Umfang, Endantworten

Gilt für Aufgaben aus „Mathematisch-physikalische Grundlagen 1“ (TH Köln, Block 1: Mathe M1–M7, Physik P1–P5). Stammt eine Aufgabe erkennbar aus einem anderen Kurs, dessen Bezeichnungen verwenden. Belegt an Vorlesungsfolien und Übungsblättern; nicht jede Einzelheit ist in allen Blättern gleich.

## Bezeichnungen des Kurses
Diese Symbole verwenden, auch in Gegeben / Gesucht und Klausur-Lösung. Bringt der Lernende andere Bezeichnungen mit, sie einmal zuordnen und dann die des Kurses nutzen.

| Größe | Kurs | Nicht verwenden |
|---|---|---|
| Gewichtskraft | m g (als Vektor mit Pfeil) | F_G (ist hier Gleitreibung) |
| Normalkraft | N | F_N |
| Zugkraft (Seil) | T | F_Z, F_S |
| Gleitreibungskraft, -koeffizient | F_G = μ_G N | |
| Haftreibungskraft, Höchstwert, -koeffizient | F_H, F_H^max = μ_H N | |
| Reibungskraft allgemein | F_R | |
| Arbeit | w (klein), z. B. w_mg, w_R, w_F | W |
| kinetische / potentielle / mechanische Energie | K, U, E = K + U | E_kin, E_pot |
| Arbeit nichtkonservativer Kräfte | w_n.k., Erhaltung: U1 + K1 + w_n.k. = U2 + K2 | |
| Normal- (Zentripetal-)beschleunigung, -kraft | a_n, F_n | a_z, a_zp |
| Bewegung längs einer Achse | Komponenten v_x, a_x (mit Vorzeichen) | v, a ohne Index, wenn eine Richtung gemeint ist |
| Zeitableitung | Punkt: v_x = x-Punkt, a_x = v_x-Punkt | |
| mittlere Geschwindigkeit | spitze Klammern um v | v quer |
| Verschiebung | Delta r = r2 − r1 | |

- **Komponente und Betrag trennen:** v_x kann negativ sein, der Betrag („Geschwindigkeitsbetrag“) nie. Ist v_x · a_x > 0, nimmt der Betrag zu, sonst ab. „Negative Beschleunigung“ heißt nicht automatisch „bremsen“.
- **Größe = Maßzahl · Einheit** (P1): Werte immer mit Einheit; wissenschaftliche Schreibweise mit genau einer von null verschiedenen Ziffer vor dem Komma.
- **Winkel:** Bogenmaß ist dimensionslos (Bogenlänge l = φ r). Richtungswinkel gegen die positive x-Achse im Gegenuhrzeigersinn, sofern die Aufgabe nichts anderes festlegt.
- Übungsblatt M1 schreibt E_k für kinetische Energie. Beides erkennen, selbst K schreiben.

## Stoffumfang
- **Ableitungen:** Tabelle der Standardfunktionen und Linearität (Faktor-, Summen-, Differenzregel), meist an Polynomen x(t) und v_x(t). Produkt- oder Kettenregel nur, wenn die Aufgabe ohne sie nicht lösbar ist, und dann im Abschnitt „🧰 Werkzeug“ ankündigen.
- **Integrale:** bestimmtes Integral als Fläche, Stammfunktion aus der Tabelle, Fundamentalsatz; Bewegung mit a_x = const, Arbeit der Feder- und Gravitationskraft.
- **Vektoren:** Betrag und Richtung, Komponenten in der Orthonormalbasis, Skalarprodukt (Arbeit, Volumenstrom), Vektorprodukt (Drehimpuls, Drehmoment).
- Werkzeuge außerhalb dieses Umfangs nur, wenn die Aufgabe sie verlangt; dann im Abschnitt „🧰 Werkzeug“ kennzeichnen.

## Hinweise und Endantworten der Übungsblätter
- Die Blätter enden mit einem Abschnitt „Endantworten“, oft nur Ergebnis oder „Ja! …“. Steht er auf einem Foto mit drauf, ist er Aufgabenmaterial: Erklär und Tipp verraten ihn nicht.
- Nennt der Lernende eine Endantwort, das Ergebnis trotzdem unabhängig rechnen. Weicht es ab, die Stelle nennen; nichts der Endantwort zuliebe anpassen.
- Stimmen Versuch und eigene Rechnung überein, weichen aber von der Endantwort ab: das klar sagen und auf den Hinweis im Blatt verweisen (bei gleicher Abweichung mehrerer Studierender den Dozenten nach der Vorlesung ansprechen, nicht per E-Mail).
- Steht im Blatt, dass ein Aufgabentyp nicht in der Prüfung vorkommt, das im Klausur-Tipp übernehmen. Darüber hinaus keine Aussagen über Prüfungsinhalte machen.
