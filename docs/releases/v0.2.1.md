Paketversion für die offiziellen Plugin-Verzeichnisse von Claude und ChatGPT/Codex. Das Tutor-Verhalten entspricht [v0.2.0](https://github.com/Sae-l/tutor/releases/tag/v0.2.0).

## Änderungen gegenüber v0.2.0

- Pluginpaket mit Claude-Manifest (`.claude-plugin/plugin.json`), README, Logo und OpenAI-Angaben (Anzeigename, Beschreibungen, Kategorie „Education & Research“, Beispielprompts). `claude plugin validate --strict` besteht.
- `tutor-chatgpt.zip` enthält README und Logo, aber nur das Agent-Plugins-Manifest.
- Gemini: Skill-Upload von `tutor-skill.zip` als Hauptweg; Gems laufen für private Konten im November 2026 aus.
- Landingpage: Einzeiler für Claude Code und Codex, Footer mit Unterstützung, Über mich und GitHub-Links.

## Installation

- Claude (Web/App): `tutor-skill.zip` unter Customize → Skills hochladen; nicht entpacken.
- Claude Code: `/plugin install tutor --marketplace Sae-l/tutor` (ab 2.1.275). Der Skill heißt `tutor:tutor`.
- Codex / ChatGPT Desktop, experimentell: `codex plugin marketplace add Sae-l/tutor`, dann in Codex `/plugins` bzw. im Pluginverzeichnis **Tutor** installieren. [Anleitung](https://github.com/Sae-l/tutor/blob/v0.2.1/docs/CHATGPT.md).
- ChatGPT im Web, experimentell: Workspace-Admins laden `tutor-chatgpt.zip` unter Admin → Plugins hoch.
- Gemini, experimentell: `tutor-skill.zip` unter Einstellungen → Skills → Erstellen hochladen.
- ChatGPT Projekt / Gemini Gem: `kern.md` als Anweisung und `system-prompt.md` als Wissensdatei.
- `sha256sum -c SHA256SUMS.txt` prüft alle Dateien.

## Nachweise und Grenzen

Build, 16 Strukturtests und Vaultprüfung laufen automatisch. **Das Lehrverhalten ist auf den Zieloberflächen weiterhin nicht abgenommen**; ChatGPT- und Gemini-Wege bleiben experimentell. Die Einreichung in die Verzeichnisse von Anthropic und OpenAI steht aus. [#32](https://github.com/Sae-l/tutor/issues/32) bleibt offen.
