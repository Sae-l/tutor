Erste stabile Version von v0.2. Das Tutor-Verhalten entspricht [v0.2.0-rc.4](https://github.com/Sae-l/tutor/releases/tag/v0.2.0-rc.4): ein gemeinsames Pluginpaket für Claude Code und Codex/ChatGPT, sichtbare Skizzen ([#45](https://github.com/Sae-l/tutor/issues/45)) und Formel-Fallback ([#44](https://github.com/Sae-l/tutor/issues/44)).

## Änderungen gegenüber rc.4

- Version `0.2.0` statt Vorabversion; Landingpage und README verweisen auf dieses Release.
- Recherchenotizen zu Lernforschung, Plattformen und Veröffentlichung in `docs/planung/` übernommen.

## Installation

- Claude (Web/App): `tutor-skill.zip` unter Skills hochladen; nicht entpacken.
- Claude Code: `/plugin marketplace add Sae-l/tutor`, dann `/plugin install tutor@tutor`. Der Skill heißt `tutor:tutor`.
- Codex CLI / ChatGPT Desktop, experimentell: `codex plugin marketplace add Sae-l/tutor`, dann **tutor** installieren. [Anleitung](https://github.com/Sae-l/tutor/blob/v0.2.0/docs/CHATGPT.md).
- ChatGPT Plugin-Importer, experimentell: `tutor-chatgpt.zip` hochladen, nicht als Chat-Anhang.
- ChatGPT Projekt / Gemini-Promptweg, experimentell: `kern.md` als Anweisung und `system-prompt.md` als Wissensdatei.
- Alle vier Dateien gemeinsam herunterladen; `sha256sum -c SHA256SUMS.txt` prüft ihre Integrität.

## Nachweise und Grenzen

Build, 16 Strukturtests und Vaultprüfung laufen automatisch. **Die Akzeptanzfälle für das Lehrverhalten (R-LS01 … R-LS14, Modus- und Grenzfälle) sind auf den Zieloberflächen noch nicht ausgeführt**; diese Version ist ohne native Abnahme freigegeben. ChatGPT- und Gemini-Wege bleiben experimentell. [#32](https://github.com/Sae-l/tutor/issues/32) bleibt offen.
