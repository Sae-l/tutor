Fünfte Vorabversion: ein gemeinsames Pluginpaket für Claude Code und Codex/ChatGPT. Das Tutor-Verhalten ist unverändert gegenüber dem Stand von `main` nach rc.3 (sichtbare Skizze [#45](https://github.com/Sae-l/tutor/issues/45), Formel-Fallback [#44](https://github.com/Sae-l/tutor/issues/44)). **Keine stabile Freigabe.**

## Änderungen

- Claude Code und Codex installieren dasselbe erzeugte Plugin `dist/chatgpt/plugins/tutor/` (18 Dateien) statt des ganzen Repositorys. `claude plugin validate` läuft ohne Warnung.
- Neuer Repo-Marketplace für Codex/ChatGPT: `codex plugin marketplace add Sae-l/tutor` funktioniert ohne eigenen Build.
- Skizzen werden sichtbar eingebettet; bei gemeldetem LaTeX-Rohcode wechselt der Tutor auf Klartextformeln. Notation nach DIN 1338 / ISO 80000.
- Landingpage, README und Wissensbasis überarbeitet.

## Installation

- Claude (Web/App): `tutor-skill.zip` unter Skills hochladen; nicht entpacken.
- Claude Code: `/plugin marketplace add Sae-l/tutor`, dann `/plugin install tutor@tutor`. Der Skill heißt `tutor:tutor`.
- Codex CLI / ChatGPT Desktop, experimentell: `codex plugin marketplace add Sae-l/tutor`, dann **tutor** installieren. [Anleitung](https://github.com/Sae-l/tutor/blob/v0.2.0-rc.4/docs/CHATGPT.md).
- ChatGPT Plugin-Importer, experimentell: `tutor-chatgpt.zip` hochladen, nicht als Chat-Anhang.
- ChatGPT Projekt / Gemini-Promptweg, experimentell: `kern.md` als Anweisung und `system-prompt.md` als Wissensdatei.
- Alle vier Dateien gemeinsam herunterladen; `sha256sum -c SHA256SUMS.txt` prüft ihre Integrität.

## Nachweise und Grenzen

Build, 16 Strukturtests und Vaultprüfung laufen automatisch. Zusätzlich lokal geprüft: `claude plugin validate`, Installation über den Marketplace in einer isolierten Claude-Code-Konfiguration und Laden des Skills `tutor:tutor` in einer Claude-Code-Sitzung; ECC-Hostprüfung ohne Claude-spezifische Variablen und mit Codex-kompatiblem Frontmatter. Nicht geprüft: Installation in Codex CLI und ChatGPT selbst. Diese Prüfungen belegen keine Modellregeltreue oder Lernwirkung; R-LS01 … R-LS14 sind noch nicht auf den Zieloberflächen ausgeführt. [#32](https://github.com/Sae-l/tutor/issues/32) bleibt offen.
